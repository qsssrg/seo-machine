Tabbyで自前のAIコード補完サーバーを立てる——VPS選びガイド

困りごとから解決へ

GitHub Copilotは便利ですが、毎月の利用料金と「コードが外部サーバーに送られる」という点が気になりませんか？特に企業の機密コードを扱う場合、セキュリティ面での不安は大きいでしょう。

実は、VPS（仮想専用サーバー）にTabbyをインストールすれば、コードを一切外に出さずに、自分たちのサーバー内でAIが補完を行う環境が実現できます。Tabbyは、ChatGPTやClaudeと同じAI技術を使ったオープンソースツール。月額費用も不要です。

この記事では、Tabbyサーバーを立てるのに最適なVPSの選び方をお伝えします。

Tabbyサーバーに必要なスペック（平易な説明）

Tabbyを動かすには、特に「GPU」という高速な計算装置が必要です。GPUは映像処理に使われる部品ですが、AI学習にも活躍します。

最低限必要な環境：

  • GPU：NVIDIA L4（エントリー向け）以上
  • メモリ：16GB以上
  • ストレージ：50GB以上

逆に言えば、これらを備えたVPSなら、ほぼすべての非エンジニアでもTabbyを運用できます。

VPS選びのチェックリスト

Tabbyサーバーに適したVPSを選ぶときは、以下を確認しましょう：

  • ✅ GPU搭載 — NVIDIA L4など実用的なGPUが用意されているか
  • ✅ 初期設定の簡単さ — ワンクリックでセットアップできるイメージがあるか、サポートが充実しているか
  • ✅ 料金体系 — 「試す」段階なら時間課金、「本運用」なら月額課金
  • ✅ 国産・老舗かどうか — トラブル時のサポート言語や信頼感
  • ✅ 解約のしやすさ — いつでも縮小・廃棄できるか
