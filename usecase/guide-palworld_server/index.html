パルワールド（Palworld）専用サーバーをVPSで立てる完全ガイド

【最初に結論を言います】

週末だけ遊ぶ → ConoHa for GAME（時間課金） 毎日・毎晩ガッツリ遊ぶ → XServer VPS for Game（月額固定） 4GBプランで安くやりたい → やめとけ（クラッシュします）

「どっちでも同じですよ」みたいな記事が多いけど、使い方によって月の料金が倍近く変わるので、ここだけははっきり書いておきます。

パルワールドのマルチプレイには専用サーバーが必要

パルワールド（Palworld）で友達と一緒に遊ぶには、専用サーバーを立てるのが最も快適です。

公式サーバーもありますが、以下のデメリットがあります：

  • 人数制限がある
  • 設定をカスタマイズできない
  • ラグが発生しやすい
  • いつサービス終了するかわからない

VPSで自分専用サーバーを立てれば、好きな設定で24時間いつでも友達と遊べます。

率直に言うと、「自分のPCをサーバーにすればいいじゃん」という話も出てくるんですが、これが思ったより不便。PCつけっぱなしは気になるし、何かあったときにリモートデスクトップで入り直さないといけないので、全然手放しにならない。月3,000円前後でそのストレスがなくなるなら、VPSにしたほうがいい。

必要なVPSスペック

パルワールドはマイクラより要求スペックが高め。 最低でも8GBプランを推奨します。

4GBプランで試したことがあるんですが、起動はするんです。でもプレイ中にメモリが足りなくなってサーバーがクラッシュする。「安いから4GBでいいか」という気持ちはわかるけど、友達を集めておいてサーバーが落ちるのは最悪なので、ここはケチらないほうがいい。8GB一択です。

損益分岐点をざっくり計算すると

  • ConoHa 8GBプランの時間単価：約7円/時間
  • XServer 8GBプランの月額：3,201円
  • 3,201円 ÷ 7円 ≈ 月457時間 → 1日15時間…

あれ、これだとほぼXServerが有利になる計算ですね。正直に書くと、ConoHaが有利になるのは「本当に週に数時間しか使わない」か「短期間だけ試したい」場面です。ガッツリ遊ぶつもりならXServerの固定料金のほうがシンプルでいい。

サーバー構築手順（XServer VPS for Gameの場合）

ステップ1：申し込み

  1. XServer VPS for Gameの公式サイトにアクセス
  2. 8GBプラン以上を選択
  3. アプリケーションで「Palworld」を選択
  4. rootパスワードを設定
  5. 申し込み完了（自動構築開始）

ステップ2：サーバー情報を確認

管理画面でIPアドレスを確認します。

ステップ3：パルワールドから接続

  1. パルワールドを起動
  2. 「マルチプレイに参加する」を選択
  3. 「専用サーバーに接続」でIPアドレスを入力
  4. 接続完了！

テンプレートを使えば、コマンド不要で完成します。

正直、「サーバー構築」という言葉でひるんでいる人が多いと思うんですが、テンプレートを選ぶだけなので本当に何もしなくていい。「Palworld」選んで、パスワード決めて、IPアドレスコピーして接続するだけ。10分でおわります。ここのハードルはほぼないと思っていい。

サーバー設定のカスタマイズ

ここが自前サーバーの本番。公式サーバーだと絶対にできないやつです。

経験値倍率の変更

ExpRate=2.0  # 経験値2倍

パルの出現率変更

PalSpawnNumRate=1.5  # パルの出現1.5倍

デス時のドロップ設定

DeathPenalty=None  # 死亡時アイテムロストなし

設定ファイルは /palworld/Pal/Saved/Config/LinuxServer/PalWorldSettings.ini にあります。

友達と遊ぶときに「デスペナなし」「経験値2倍」にするだけで、かなりカジュアルに楽しめます。ガチ勢には邪道と言われそうだけど、仕事終わりにサクッと遊びたいならこういうカスタマイズができるのが自前サーバーの強みなので、遠慮なく使えばいい。

よくある質問（FAQ）

起動はできますが、プレイ中にメモリ不足でクラッシュする可能性が高いです。パルワールドは最低8GBプランを推奨します。
現時点ではPC版（Steam）のみ専用サーバーに対応しています。コンソール版は公式サーバーまたはP2Pでのマルチプレイとなります。
