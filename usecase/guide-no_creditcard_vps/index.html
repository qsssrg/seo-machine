結論から書く

クレカなしでVPSを契約したいなら、ConoHa VPS一択に近い。

理由はシンプルで、コンビニ払い・PayPay・口座振替の3つすべてに対応しているのがConoHaだけだから。「今日中に使い始めたい」なら特にそう。

さくらのVPSも口座振替と銀行振込は使えるけど、口座振替の登録完了まで1〜2ヶ月かかる。急ぎじゃないならさくらもありだけど、そうじゃなければConoHaで決めていい。

XServerはクレカ専用。クレカなしだと詰む。以上。

ConoHa VPS：最多の決済方法に対応

ConoHa VPSはクレカ不要派にとって最も選択肢が広いサービス。コンビニ払い・PayPay・口座振替のすべてに対応しており、スマホだけで契約が完結する。

自分がいいなと思うのは「プリペイド方式」という仕組みで、事前にチャージしておけばあとは自動で引き落とされていく。毎月コンビニに行く必要がない。これ、地味に精神的にラク。

コンビニ決済の手順

  1. ConoHaアカウントを作成（メールアドレスのみで登録可）
  2. 管理画面「チャージ」→「コンビニ/ペイジー」を選択
  3. 払込票番号を取得してコンビニのATMまたはレジで支払い
  4. 入金確認後（通常数分〜1時間）にVPSを申し込む
# 入金確認後にConoHaコントロールパネルでVPS作成
# プラン選択 → OSイメージ選択 → rootパスワード設定 → 作成

手順としては「チャージ → VPS作成」の2ステップだけ。難しいことは何もない。

PayPayで払う場合

ConoHaはPayPayにも対応している。スマホアプリのPayPayで支払えるため、銀行口座があればすぐ使える。残高不足でも銀行口座から即時チャージできるのが便利。

はっきり書いておくと、PayPayが使えるVPSってConoHaくらいしかない。PayPay経済圏で生きている人にはConoHa一択になる理由がここにもある。

さくらのVPS：口座振替と銀行振込が使える老舗

さくらのVPSは運営歴が長く、口座振替と銀行振込に対応している。コンビニ払いはないものの、銀行振込は振込先さえわかれば誰でも使える。

口座振替の申し込み手順

  1. さくらインターネット会員登録
  2. 「会員メニュー」→「支払い方法」→「口座振替申請書請求」
  3. 書類が郵送される（約1週間）
  4. 金融機関に書類を提出→登録完了まで1〜2ヶ月

率直に言うと、この1〜2ヶ月はかなりネック。「今すぐ使いたい」という状況なら完全に間に合わない。ただ、「どうせ口座引き落としにするつもりだし、急がない」という人にとってはさくらのVPSは全然ありな選択肢。老舗の安心感はある。

口座振替は審査・書類提出が必要なため、すぐに使いたい場合はコンビニ払いのあるConoHaが便利です。

高校生・大学生でも保護者の同意と支払いがあれば契約できるサービスがほとんど。ConoHaはコンビニ払いなので保護者と一緒にコンビニに行けばすぐ払える。

自分の場合の判断で言うと、学生で「VPS試してみたい」というモチベーションがあるなら、ConoHaのコンビニ払いが一番ハードルが低い。保護者に「コンビニで○○円払ってほしい」と頼むだけで始められる。額面で言えば最小プランなら月々数百円〜1,000円前後の話なので、相談しやすい金額だと思う。

クレカなしで契約する際のよくある失敗

これは自分も調べていて「やりがちだな」と思ったやつを書いておく。

  • 仮想プリペイドカード（Visaギフトカード等）を試みて弾かれる → VPSは本人確認と継続課金のため仮想カードは多くの場合拒否される。時間を無駄にするだけなのでやめとけ
  • 銀行振込の入金タイミングで時間がかかりサーバー停止 → 事前チャージ方式のConoHaなら残高がある限り継続できるので、この問題が起きにくい
  • コンビニ払い期限切れ → 払込票には有効期限があるので期限内に払うこと。当日中か翌日中に行くくらいの気持ちでいた方がいい

FAQ

A. VISAやMastercardのデビットカードであれば、多くのVPSでクレジットカードと同じ扱いで使えます。ただし残高不足で引き落とし失敗するとサーバーが停止するため、定期的な残高確認が必要です。
A. ConoHaはプリペイド方式なので、まとめてチャージすれば自動引き落としになります。毎月コンビニに行く必要はありません。残高が少なくなったらまとめてチャージするスタイルが一般的です。
A. 2026年7月時点ではXServer VPSはクレジットカード払いのみとなっています。クレカなしで使いたい場合はConoHaかさくらのVPSを選んでください。
