VPSの月額と時間課金、どっちが安い？損益分岐点を計算して選ぶ方法

筆者の結論（最初に読んでください）

はっきり書いておきます。

Claude Code目的でVPSを借りるなら、GPUプランは不要です。

Claude CodeはAPI経由でAIを動かす仕組みなので、VPS側にGPUは一切いりません。「GPU搭載プランで高速化！」みたいな記事を見かけたら、アフィリエイト報酬目的で単価の高いGPUプランに誘導している可能性を疑ってください。自分も最初は騙されかけました。

料金の選び方も、シンプルに計算できます。

  • 月76時間以上使う → XServer VPSの月額固定（830円〜）が安い
  • 月76時間未満 → KAGOYAの時間課金（11円/時）が安い
  • まず試したい → KAGOYAの14日無料お試しから始める

これが自分の出した結論です。以下でその根拠を説明します。

VPSの月額と時間課金、どちらが安いか見極めたい

「月に何時間使うか」だけ考えれば答えが出る

料金体系の話をする前に、一個だけ確認させてください。

「自宅PCを立ち上げっぱなしにすればVPSいらないんじゃ？」という考え、持っていませんか？

自分も最初そう思っていたんですが、これは精神的にしんどいです。何かあったとき外出先からリモートデスクトップで入らないといけないし、PCが落ちてたら終わり。「手放し感」が全然ない。VPSを借りると、その精神的なコストがゼロになります。月数百円〜で買える安心感なので、これは早めに割り切った方がいいです。

というわけで、VPSを借りる前提で話を進めます。

損益分岐点を計算する

VPSの料金体系は2種類あります。

月額固定型：毎月決まった金額を払って使い放題。使っても使わなくても同じ金額。
時間課金型：起動した時間分だけ料金が発生する。電気代と同じイメージ。

どちらが安いかは、月に何時間使うかで決まります。

自分の場合で計算してみた（Claude Code用途）

Claude Code向けのスペック（8コア/16GB程度）で比較します。

プラン料金
XServer VPS 月額固定（8コア/16GB相当）約830円/月
KAGOYA CLOUD VPS 時間課金（8コア/16GB）11円/時

損益分岐点の計算：

830円 ÷ 11円/時 ≒ 75.5時間

つまり月76時間が分かれ目です。

  • 月76時間以上使う → XServerの830円固定の方が安い
  • 月76時間未満 → KAGOYAの時間課金の方が安い

月76時間というのは、1日あたり約2.5時間。毎日まとまった時間使うなら固定、週末だけ・気が向いたときだけなら時間課金という感じです。

1日あたりに換算すると：

  • XServer 830円/月 = 1日あたり約28円
  • KAGOYA 11円/時 × 実使用時間分だけ

週末2日だけ、1日3〜4時間使う程度なら月約88〜176円。KAGOYAの圧勝です。

ただし、XServerの830円固定は無視できない

正直に言うと、XServerの月830円という価格は「安い時間課金」に匹敵するレベルで安いです。

1日あたり28円で「月額が読める・何時間使っても同じ・毎月いくらか計算しなくていい」という精神的なラクさは結構大きい。「毎月いくらになるか気にしながら使うのが嫌」という人には、ちょっとKAGOYAより多く払っても固定の方が向いてます。

自分はどちらかというとKAGOYA派ですが、XServerを選ぶ理由もちゃんとあります。

無料お試しの話：KAGOYAの14日間は「あり」

KAGOYAには14日間の無料お試し期間があります。これ、地味にありがたい。

なぜかというと、14日間に週末が2回入るからです。

平日は仕事があってVPSをゆっくり触れないことが多い。でも週末2回あれば、「セットアップ → 動作確認 → 本当に使えるか検証」が十分できます。失敗しても料金ゼロ。

「まず試してから決めたい」という人は、KAGOYAの無料お試しから入るのが一番リスクが低いです。

チェックリスト：自分に合う料金体系を診断

  • ☐ 毎日2〜3時間以上Claude Codeを使っている（月76時間以上）
  • ☐ 週末だけ、または気が向いたときだけ使う（月76時間未満）
  • ☐ 毎月の料金が変動するのが気になる
  • ☐ 最初は無料でリスクなく試したい
  • ☐ セットアップをできるだけ楽にしたい

選び方のポイント（用途別）

「毎日使う・月76時間以上」に当てはまった方

XServer VPSの月額固定が経済的かつ精神的にラクです。毎月830円で計算が固定されるので、料金を気にせず使えます。

「週末だけ・試験的に使いたい」に当てはまった方

KAGOYAの時間課金が断然お得。まず14日間の無料お試しから始めてみてください。

「GPU搭載プランが気になっている」方

Claude Codeの用途なら、はっきり言ってGPUは必要ありません。API経由でAIを動かすので、VPS側のGPUは関係ない。月数万円のGPUプランを勧めてくる記事は、その理由を一度疑った方がいいです。

ただし、Stable Diffusionで画像生成をローカルで回したい場合は話が変わります。GPU VPSも選択肢に入りますが、月数万円はまぁまぁ高い。「立ち上げが楽で使い勝手が良いなら検討する価値はある」くらいの温度感で見てください。

「ゲームサーバーを立てたい」方

「やってみたいと思ったのなら、一度やってみてください」というのが自分の答えです。これが最終回答じゃないので。合わなければ解約すればいい。時間課金なら初期コストも低いです。
