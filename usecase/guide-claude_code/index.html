Claude Code / Codex を24時間動かすならVPS！自宅PCの負担を減らす選び方ガイド

【開いた瞬間に読んでほしい】自分の結論

Claude CodeにGPUは要りません。これだけ先に言っておきます。

「Claude Code向けにGPUプランがおすすめ！」と書いてある記事を見かけたら、正直に言います。アフィリエイト報酬が高いGPUプランを売りたいだけです。 GPU VPSは月2〜5万円の世界。Claude CodeはAPIを経由してAnthropicのサーバー側で処理が走るので、あなたのVPSにGPUが乗っている必要はゼロです。騙されないでください。

で、自分の結論はこうです：

あなたの使い方選ぶべきもの
月76時間以上Claude Codeを動かすXServer VPS（830円/月固定）
月76時間未満、または様子見したいKAGOYA CLOUD VPS（11円/時）
まず2週間タダで感触を掴みたいKAGOYAの14日無料お試し

この3行が自分の結論のすべてです。以下はその根拠と補足なので、「もう決まった」人は目当てのVPSのリンクに飛んでください。まだ迷ってる人は読み進めてください。

自宅PCでAIツールを常時起動するのはもう卒業しましょう

正直に言うと、自分も最初は自宅PCでClaude Codeを動かしていました。で、やっぱりダメでした。理由は電気代とかスペックとかより、もっと精神的なところにあって。

PCを手放せないんです。

「落ちたらどうしよう」「エラーが出てないか」って気になる。外出先からリモートデスクトップで確認しに行く羽目になる。それって全然「24時間自動で動かしてる」じゃないですよね。管理をサボれていない。「手放してる」という感覚が全くない。

VPSにしたら、その感覚がすっと消えました。データセンターで動いているから、自分のPCが関係ない。完全に手放せる。この精神的なラクさは、月数百〜数千円払う価値が普通にあります。

具体的な問題を列挙するとこうなります：

  • PCが重くなって、他の作業ができない
  • 電気代が毎月跳ね上がる
  • 24時間つけっぱなしでハードウェアが劣化する可能性
  • 何かあったときに自分が対応しないといけない（これが一番きつい）

VPSならこれが全部解決します。「インターネット上の借りたPC」を遠隔操作するだけ。自宅PCは関係ない。「何かあってもデータセンターの問題」と割り切れる。この感覚の違いは、使ってみないとわからないかもしれないけど、本当に大きいです。

【重要】Claude CodeにGPUは不要という話、もう少し詳しく

もう少し詳しく書かせてください。これを理解してないと、余計な出費をする羽目になるので。

Claude CodeやCodexは、APIを通じてAIの処理をクラウドに投げる仕組みです。あなたのVPSがやることは「コードを送って、結果を受け取る」だけ。GPUを使う処理は一切ありません。

つまり、VPSに求めるのは：

  • メモリ 8GB以上（複数プロセス走らせるなら）
  • CPUがそこそこ（処理待ちでストレスにならない程度）
  • 回線が安定している

これだけです。月数百〜数千円の普通のVPSで十分動きます。

「じゃあGPU VPSはいつ使うの？」という話は後で書きますが、Claude Code目的では本当に必要ない。GPU VPSは月2〜5万円かかる世界です。不要なコストを払わないでください。

はっきり書いておきます。「GPU装備されているか」はチェックリストから外していいです。

VPS選びのチェックリスト

実際に選ぶときに確認したい項目です。Claude Code用途に絞って書きます。

  • GPU不要プランがあるか（月数百〜数千円の普通のVPS）
  • メモリ8GB以上のプランがあるか
  • 料金体系が明確か（時間課金 or 月額固定、どちらが自分の使い方に合うか）
  • 無料お試しがあるか（失敗リスクを下げるために重要）
  • Claude Code用のセットアップ手順があるか（自分で0から構築は面倒）

繰り返しますが、「GPU装備されているか」はこのチェックリストに入れなくていいです。

XServer vs KAGOYA、自分が計算した損益分岐点

ここが一番重要なので、具体的に計算します。「なんとなく安そう」で選ぶのをやめて、数字で判断しましょう。

KAGOYA CLOUD VPS（8コア/16GB）

  • 料金：11円/時
  • 月100時間使う場合：11円 × 100時間 = 1,100円
  • 月50時間使う場合：11円 × 50時間 = 550円

XServer VPS（月額固定プラン）

  • 最安プラン：830円/月（固定）
  • 何時間使っても830円、使い放題

損益分岐点の計算：

KAGOYA = XServer
11円/時 × X時間 = 830円
X = 830 ÷ 11 = 75.4時間

月76時間以上使うならXServer、未満ならKAGOYA。

1日あたりに換算すると、76時間 ÷ 30日 ≈ 2.5時間/日。「ほぼ常時起動」するなら余裕でXServerが得。「週末だけ触る」「仕事の合間に少し使う」程度ならKAGOYAの方が安い。

自分の場合、「毎月いくらになるか計算したくない」タイプなので、固定料金の830円は精神的にラクです。使いすぎを気にしなくていい。1日あたり約27円。コーヒー1杯より安い固定料金に切り替えるのは、「毎月の請求を気にせず動かしたい」人には本当におすすめです。一方で「そんなに使わないかも」という人はKAGOYAで様子見した方が絶対いい。「なんとなくXServerの方が有名だから」という理由で選ぶのは、使い方によっては普通に損です。

「14日無料お試し」の価値について

KAGOYAの14日無料は、地味に良い設計です。

14日間 = 週末が2回入る。

平日は仕事があって触れなくても、土日が2回あれば「ちゃんとClaude Codeが動くか」「自分の使い方に合うか」の確認は十分できます。無料でそれができるなら、試さない理由がない。

「14日じゃ短い」という声もたまに聞くけど、正直そんなに悩む必要ないと思っています。週末2回あれば動作確認としては十分で、それ以上悩む時間の方がもったいない。

XServerには14日無料はありませんが、830円という金額なら「とりあえず1ヶ月試す」ハードルは低いです。1日あたり約27円。失敗してもダメージが小さい。「無料じゃないと嫌だ」という人はKAGOYAから入って、使い方が固まってきたらXServerに移行する流れが一番リスクが低いと思います。

【番外】GPU VPSが「あり」になるケース

ここまで「GPU不要」と書いてきましたが、GPU VPSが意味を持つ用途はあります。フェアに書いておきます。

Stable Diffusionなどのローカル画像生成を動かしたい場合。

ローカルで推論処理を走らせる用途なら、GPUが必要になります。月2〜5万円かかるので「まぁまぁ高い」ですが、立ち上げが楽で常時使えるなら選択肢としてはあり、だと思っています。「毎回ローカル環境を立ち上げるのが面倒」という人には向いているかもしれない。ただしこれはClaude CodeやCodexとは完全に別の話です。用途をごっちゃにしないように。

Claude Code用途でGPU VPSを勧めてくる記事を見かけたら、その記事の他の情報も少し疑った方がいいかもしれないです。「GPU推し＝アフィ報酬目的」という構図はVPS記事の中でわりと見かけます。
