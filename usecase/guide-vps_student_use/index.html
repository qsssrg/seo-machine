【筆者の結論】記事を読む前に、これだけ見てください

Claude Code目的なら、GPUは要りません。はっきり書いておきます。

Claude CodeはAPI経由で動くので、GPU搭載VPSを選ぶ意味がそもそもない。「AI用VPS＝GPU必須」みたいな記事を見かけますが、Claude Code用途でGPUを推してくるのはアフィリエイト報酬が高いからです。GPU VPSは単価が高い。それだけの話。

で、結論。

  • 月76時間以上使うなら → XServer VPS（830円固定、ずっと立ち上げっぱなしOK）
  • 月76時間未満なら → KAGOYA CLOUD VPS（11円/時の時間課金、使った分だけ）
  • まず試したいだけなら → KAGOYA 14日無料から始めて判断

自分はVPSが「手放し運用できる」かどうかをかなり重視しています。自分のPCを立ち上げっぱなしにする構成は、正直ストレスがある。何かあったときにリモートデスクトップで入らなきゃいけないし、電気代も気になるし、精神的に「ちゃんと動いてるかな」って頭の片隅に残り続ける。VPSにしておけば、それが全部消える。

以下、詳しく説明します。

ChatGPTやClaudeを使い始めたあなたへ。「固定月額」なら予算の心配がなくなります

従量課金サービスで「今月いくら来るんだろう」って不安になった経験、ありませんか。自分も最初はそれで本気で試せなかった。

VPSの固定月額プランは、その不安が消える。月830円なら、1日あたり約27円。コンビニコーヒー1杯以下です。 それで24時間使える自分のサーバーが持てる。

ただ、「固定月額がいいか、時間課金がいいか」は使い方で変わります。ここを間違えると損するので、後で計算式ごと書きます。

「GPU必要」という情報を鵜呑みにしないでください

正直に言うと、AI用VPSの記事でGPUをやたら推しているものは、一度疑ってみてください。

Claude CodeはAnthropicのAPIを叩いて動きます。つまり、重い処理はAnthropicのサーバー側でやってくれる。VPS側に必要なのはコードを実行できる普通のCPUと、安定したネット回線だけです。

GPUが必要なのは：

  • Stable DiffusionなどをローカルVPS上で動かしたい
  • LLMのモデルファイル自体をVPS上に置いてローカル推論したい

こういうケースだけ。Claude Codeなら関係ない話。

Stable DiffusionをGPU VPSで動かすのは、セットアップが楽になってきたならアリだと思います。ただ月数万円になるのはまぁまぁ高い。「どうしても試したい」という気持ちがあるなら時間課金で数時間試してみて、それから判断するのがいい。

学生・個人が予算内でAI用VPSを持つために必要な「3つのポイント」

1. 固定月額か時間課金か、先に計算する

「固定月額＝安心」は正しい。でも使用時間が少ないなら時間課金の方が安くなることもある。

KAGOYAの8コア/16GBプランで計算すると：

  • 時間課金：11円/時
  • 月76時間の場合：11円 × 76時間 = 836円
  • XServer VPS 最安固定プラン：830円/月

つまり、月76時間が損益分岐点。毎日2時間半以上使うならXServer固定の方が得。週末しか触らないなら、KAGOYAの時間課金で十分。

「毎月いくらか計算したくない」「使いすぎが怖い」という人には、XServerの830円固定が精神的にラクです。これは無視できない。

2. GPU搭載を確認する（Claude Code目的なら不要）

上でも書きましたが、Claude Code目的ならGPUは要りません。予算を無駄にしないために、ここだけはちゃんと判断してほしい。

GPUが必要な用途なら、コストと立ち上げの手間をセットで考えてください。

3. セットアップが簡単か確認する

これは本当に大事。難しい設定に時間を取られて、本来やりたかったAI学習が進まない、というのが一番もったいない。XServerのワンクリック構築は、初心者には素直にありがたいと思います。

選び方のチェックリスト【自分はどのタイプ？】

  • 「まず無料で14日試してみたい」 → KAGOYAの14日無料が最適。週末が2回入るので、平日に仕事で触れなくても確認は十分できます
  • 「Claude CodeやCodex専用で、ワンクリック構築したい」 → XServer VPS一択。設定で詰まる時間がもったいない
  • 「月額じゃなく使った時間分だけ払いたい」 → KAGOYA時間課金（11円/時）が低リスク
  • 「将来的にGPUも使いたいかもしれない」 → XServerにGPUプランあり。ただし時間課金のみ。本当に必要になってから考えても遅くない
