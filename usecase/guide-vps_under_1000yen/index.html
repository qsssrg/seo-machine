月1,000円以下でAIツールを動かせるVPS選び方ガイド｜2026年6月最新版

最初に結論を書きます

Claude CodeやCodex目的なら、GPUは不要です。VPS（CPU）で十分動きます。

これ、はっきり書いておきます。API経由で動く構成なので、GPU性能はそもそも関係ない。それなのに「GPU搭載プランがおすすめ！」と煽っている記事があったら、アフィリエイト報酬が高い商品に誘導したいだけだと思ってまず間違いない。

この記事、最初から最後まで読まなくても上の表で判断できると思います。ただ「なぜそう言えるのか」を知りたい方は続きへどうぞ。

「AIツール試したいのに高い…」をVPSで解決する

ChatGPTやClaude、Codexなどが普通に使われるようになって、「自分専用のAI環境を作ってみたい」と思う人が増えてきた。でも調べると「GPUサーバー月数万円〜」みたいな情報ばかり出てきて、気づいたらやる気をなくす、というパターン。自分もそれをやりました。

正直に言うと、ほとんどの用途はCPUのVPSで十分で、月1,000円以下で始められます。VPSとは「インターネット上に自分専用のPCを持つ」イメージ。自分のPCを立ち上げっぱなしにしておく方法もあるけど、あれは精神的に気になる。何かあるたびにリモートデスクトップで入らないといけないし、全然「手放し」にならない。だからVPSを借りるのが正解です。

必要なスペックの話｜GPU推しには乗らなくていい

ここで一回立ち止まって考えてほしいのですが、「AIツール = GPU必須」は間違いです。少なくともClaude CodeやCodex目的では。

API経由でAIを使う場合、計算はClaudeやOpenAIのサーバー側でやってくれます。あなたのVPSはその「窓口」になるだけ。だからGPUに金を払う必要がない。

必要なのはこれだけです。

メモリ（作業机の広さ）

  • 軽量なAIツール試用：2GB～4GB
  • 安定運用：4GB以上

CPU（処理速度）

  • 最初は1〜2コアで十分
  • 本格化してきたら2コア以上

GPU

  • Claude Code / Codex目的では不要
  • Stable Diffusionなど画像生成をローカルで回したい場合は必要。ただしコストが跳ね上がる

ストレージ

  • 試験運用：20〜50GB
  • 本格利用：100GB以上

「最初は最小限で始める」が鉄則。後から増やせるのがVPSの良いところ。最初から盛るのは、料理の味見せずに全部の調味料ぶち込むようなもの。

具体的な金額で考える｜損益分岐点を計算しておく

ここが一番大事な話なので、具体的に計算します。

KAGOYAの時間課金（8コア/16GB）：11円/時

  • 10時間/月 → 110円
  • 50時間/月 → 550円
  • 76時間/月 → 836円
  • 100時間/月 → 1,100円

XServer VPSの固定料金（CPU）：830円/月

  • 何時間使っても830円固定

損益分岐点：月76時間

76時間 × 11円 = 836円 ≒ XServerの830円

つまり、月76時間以上VPSを起動するならXServer固定が得。未満ならKAGOYAの時間課金が得。

自分の場合、仕事の合間にClaude Codeを使う程度なら月40〜50時間くらいになりそうで、KAGOYAの方が安くなる計算。でも「毎月いくらになるか計算したくない」という人には、XServerの830円固定は精神的にラクという側面もある。これは正直どちらも正解です。

VPS選びで確認すること｜3つだけ

余計な情報は省いて、本当に見るべき点だけ書きます。

① セットアップがどれくらいラクか
ワンクリックでAI環境を作れるか。ここで差がある。XServerはClaude Code / Codex環境をワンクリックで作れるので、コマンドが苦手な人には助かる。

② 無料お試し期間があるか
KAGOYAの14日間無料は正直かなりありがたい。「2週間あっても平日は仕事で触れないじゃないか」と思うかもしれないけど、14日あれば週末が2回入ります。2回の週末で動作確認するには十分。

③ 日本語サポートがあるか
詰まったときに日本語で相談できる窓口があるかどうか。長く使うなら気にしておいた方がいい。
