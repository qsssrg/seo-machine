VPSのディスク容量不足「No space left on device」を素早く解消する選び方ガイド

【先に結論を書いておきます】

Claude Code目的でVPS使ってるなら、GPUプランは不要です。 はっきり言います。

Claude CodeはAPI経由で動くので、VPS側にGPUは一切要りません。それなのにGPU推しの記事が多いのは、GPU課金の方がアフィリエイト報酬が高いからです。この記事ではそういう忖度はしません。

「No space left on device」が出た人への判断をまとめると：

あなたの状況まずやること
とにかくすぐ直したいSSH接続してログ・キャッシュ削除（無料、今すぐできる）
削除しても足りない同じVPSの上位プランに変更、またはVPS乗り換え
Claude Code用途CPU固定プラン100GB以上。GPUは要らない
画像生成（Stable Diffusion）目的GPU VPSあり、ただし月数万は覚悟して

細かい話は以下で書きます。

困りごとから解決まで

「No space left on device」、初めて見たとき焦りますよね。自分も最初は何が起きたかわからなくて、数時間無駄にしました。

でも落ち着いて見ると、原因はほぼ3つに絞られます。

  • 不要なファイルの蓄積（データセット、テンポラリファイルなど）
  • ログファイルの肥大化（AIツールの実行記録がひたすらたまってる状態）
  • キャッシュの蓄積（一時データがクリアされていない）

正直に言うと、最初の対処としてVPS乗り換えは早計です。まず「今あるVPSで空きを作る」を試してください。SSH接続でコマンド数本打つだけで、数GB〜数十GB空くことがほとんどです。

# 容量確認
df -h

# 大きいファイルを探す
du -sh /* 2>/dev/null | sort -rh | head -20

# ログのクリア（journalctl）
sudo journalctl --vacuum-time=7d

# パッケージキャッシュ削除（Ubuntu/Debian系）
sudo apt clean

これで解決するなら、VPS乗り換えコストはゼロです。

それでも足りない場合：根本解決の話

一時的な整理で追いつかなくなったなら、最初から容量に余裕を持ったVPSに乗り換えるのが正解です。

用途別の目安

自分の経験と、実際に使ってる人の声をもとにした目安です：

用途最低ライン現実的な推奨
Claude Codeだけ50GB100GB（ログがたまる）
テキスト系AI処理100GB200GB
画像生成（SD等）200GB300GB以上
大規模データ処理300GBSSD追加前提

「まだどの程度必要か分からない」という人は、後から拡張できるVPSを選ぶのが一番ストレスが少いです。

ここは正直に言っておきます：Claude CodeにGPUは要りません

Claude CodeはAnthropicのAPIサーバーに処理を投げます。VPS側はAPIリクエストを送る「端末」に過ぎない。GPU積んでいても、Claude Codeの推論速度は1ミリも変わりません。

GPU VPSは月数万円かかります。Claude Code用途でそこに払うのは完全に無駄です。

GPU VPSが必要なのは：

  • Stable Diffusionなど、ローカルで推論するモデルを動かす場合
  • 機械学習モデルのトレーニングをVPS上でやる場合

これだけです。それ以外の用途でGPUを勧めてくる記事は、費用対効果の観点からおかしいと思ってください。

選び方のチェックリスト

VPS選びで確認すべきことを整理します。

  • ディスク容量の余裕：必要容量の1.5〜2倍を目安に選ぶ
  • 拡張可能か：ディスク・メモリを後から増やせるか確認
  • 管理画面の使いやすさ：非エンジニア向けにわかりやすい操作画面か
  • サポート体制：日本語サポートがあるか、初心者対応か
  • 料金体系：月額固定か時間課金か、予算に合致しているか

まとめ：あなたの使い方で選ぶ

はっきり書いておきます。「どれが最強か」より「自分の使い方に合ってるか」の方がずっと重要です。

損益分岐点の話

XServer（830円/月固定）とKAGOYA（約11円/時間）の場合：

  • 830円 ÷ 11円 = 月75.4時間
  • つまり月76時間以上使うなら→XServer固定が得
  • 月75時間以下なら→KAGOYA時間課金が得

1日あたり換算すると、2.5時間/日が境目です。常時立ち上げっぱなしにするならXServer一択。週末だけ使う程度なら時間課金の方が安いです。

ちなみに、自分がVPSを使い続ける理由は「PCを立ち上げっぱなしにしたくないから」です。PCが手元にないときに何かあったら、リモートデスクトップで入らないといけない。それが地味にストレスで、全然「手放し」にならない。VPSにしてからその気持ちが完全になくなりました。

最終回答じゃないんだから、まずは試してみてください。「やっぱり違った」なら乗り換えればいい。それだけの話です。
