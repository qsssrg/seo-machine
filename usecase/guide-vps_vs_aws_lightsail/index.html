VPSとAWS Lightsail、初心者向けを選びたい人のための完全ガイド

はっきり言います。初心者がAWS Lightsailを選ぶ理由は、ほぼない。

結論から書きます。

Claude CodeやAI開発目的で「AWS Lightsailか国内VPSか」で迷っているなら、国内VPSを選んでください。 AWS Lightsailは設定項目が多く、初見で迷子になります。英語ドキュメントを読み解く時間が、そのままセットアップの挫折率になる。

自分もAWS触ったことありますが、「なんでこんなに設定することあるんだ」と思いました。慣れれば便利なのはわかる。でも最初からそこに時間を使う必要はない。

自分の結論：

  • Claude Code用途 → KAGOYAかXServer（GPUは不要、理由は後述）
  • 月76時間以上使う → XServer（月830円固定が得）
  • 週末だけ試したい → KAGOYA（14日無料、週末2回入る）
  • Stable DiffusionなどGPU用途 → XServer GPUプランかConoHa（ただし月数万になるのは覚悟して）

判断テーブルは記事末尾にまとめてあります。まず自分の用途を確認してから、必要なところだけ読んでください。

※2026年6月時点の情報です

「GPU推し」の記事を見たら一度立ち止まってほしい

正直に書いておきます。

Claude Codeの実行にGPUは不要です。 Claude CodeはAnthropicのAPIを経由して動くので、処理はAnthropicのサーバー側でやってくれる。VPS側のGPUがどれだけ積んであっても、Claude Codeの速度には関係ない。

にもかかわらず「Claude Code向け」として高額なGPUプランを推している記事があります。GPU付きプランはアフィリエイト報酬が高くなりやすい。それが理由であることが多い。

「GPUがあった方が将来的に使える」は一理ある。でもそれは別の用途の話。Claude Codeを動かしたいだけなら、CPUプランで十分です。 余分なお金を払う必要はない。

VPSは必要か？自分のPCで動かしちゃダメなの？

これも聞かれることが多いので書いておきます。

自分のPCで動かすのは、正直おすすめしない。

理由は2つ。

  1. PCを常時起動しておかないといけない。電気代もそうですが、「PCつけっぱなしで出かける」のが精神的に気になる人は多い。自分もそうでした。
  2. 何かあったらリモートデスクトップで入らないといけない。結局手放しで使えないので、「自動化してラクしたい」という目的が半分しか達成できない。

VPSにしてしまえば、そのへんの心配がなくなります。月数百円〜1,000円程度で「常時稼働するサーバー」が手に入ると思えば、安いと感じる。

押さえるべき3つのポイント（初心者向け）

1. セットアップが簡単か

AWSは自由度が高い分、ネットワーク設定・セキュリティグループ・IAMロール……と、最初に決めることが多すぎる。国内VPS業者の中には、Claude Code環境をワンクリックで自動構築してくれるサービスがあります。これが初心者には一番大きい。

2. 料金体系が自分の使い方と合っているか

「毎月何時間使うか」を正確に読める人はほとんどいない。時間課金か固定料金か、どちらが自分に合うかを判断するのが先です。

簡単な損益分岐点の計算：

  • KAGOYAの8コア/16GBプランは11円/時
  • XServerの月額固定プランは830円〜

11円 × 時間 = 830円 → 約76時間が損益分岐点

月76時間以上（1日2.5時間以上）使うならXServerの固定料金が得。それ未満ならKAGOYAの時間課金の方が安い。「毎月いくらかかるか計算したくない」という人には、XServerの固定料金の方が精神的にラクというのもある。

3. サポートが日本語か

困ったとき、英語でStackOverflowを漁る時間は初心者には痛い。日本語でチャット・電話できる国内業者の安心感は地味に大きい。

あなたの用途を確認するチェックリスト

  • Claude CodeやAI開発環境をサクッと作りたい → ワンクリック構築 + CPUプランで十分
  • まず試してみたい、失敗が怖い → 時間課金か無料トライアルから入る
  • 毎月の料金を固定したい → 月額固定プランを選ぶ
  • Stable DiffusionなどGPU処理が必要 → GPU VPSを検討（ただし月数万になる覚悟で）
  • ゲームサーバーを建ててみたい → やりたいと思ったならやってみればいい。これが最終回答じゃないから

まとめ

正直に言うと、AWS Lightsailを初心者に勧める気にはなれない。設定の複雑さと英語の壁で、途中で詰まる可能性が高い。国内VPSの方が、同じ目的を達成するのに圧倒的に速い。

Claude Code目的でGPUプランを勧めてくる記事は一度疑ってほしい。GPUは不要です。その分のコストを別に使った方がいい。

迷ったら：

  • 固定料金でラクしたい → XServer（月830円）
  • まず無料で試したい → KAGOYA（14日間、週末2回分）

これが今時点の自分の判断です。半年後に変わっているかもしれないし、あなたの使い方次第で答えは変わる。でも「何も試さないまま迷い続ける」のが一番もったいない。

最終回答じゃないんだから、まずは試してみてください。
