XServer VPS vs KAGOYA CLOUD VPS — Claude Code用にどっちを選ぶ？

筆者の結論：Claude Code用途ならKAGOYA寄り。ただしXServerの830円は無視できない

先に本音を言います。Claude CodeをVPSで動かすなら、自分ならKAGOYA CLOUD VPSを選びます。

理由はシンプルで、Claude CodeはAPI経由で動くツールなのでGPUが要りません。GPUが要らないなら、KAGOYA の時間課金11円/時のほうがXServerのGPU 150円/時より圧倒的に安い。

ただし、XServer VPSの月額830円〜という固定プランは正直気になります。「毎月いくらかかるか計算したくない」タイプの人には、こっちのほうが精神的にラクかもしれません。

以下、具体的に比較していきます。

そもそもClaude CodeにGPUは必要か？ — 要りません

これ、最初に言っておきたいポイントです。

Claude Codeの処理はAnthropicのサーバー側で実行されます。VPSがやるのは「Claude CodeのCLIを動かして、APIにリクエストを送る」だけ。つまりVPS自体にGPU（高価なAI処理用の部品）は不要です。

にもかかわらず、多くの比較サイトがGPU付きプランを推しているのは、正直なところアフィリエイト報酬が高いからだと思います。読者のためにならない推薦はしたくないので、はっきり書いておきます。

Claude Code用途なら、CPUプランで十分です。

料金比較 — 「月額固定」と「時間課金」、どっちが得か

XServer VPS

  • 月額固定 830円〜（2GBプラン）
  • 時間課金なし（月額のみ）
  • GPU（L4）は150円/時の時間課金

KAGOYA CLOUD VPS

  • 月額固定 1,980円〜（8コア/16GBプラン）
  • 時間課金 11円/時
  • GPUプランなし

筆者の判断

ここが悩みどころです。

XServerの830円/月は業界最安クラス。毎月決まった額だけ払えばいいので、「今月いくら使ったっけ？」と考えなくていい。これは地味に大きいです。

一方、KAGOYAの時間課金11円/時は、使う時間が限られている人には有利。たとえば平日は仕事で触れない、週末だけVPSでClaude Codeを回すという使い方なら：

  • 週末だけ（土日×8時間）= 月64時間 × 11円 = 月704円
  • → XServerの830円より安い

逆に24時間365日動かすなら：

  • 24時間 × 30日 × 11円 = 月7,920円
  • → XServerの830円のほうが圧倒的に安い

つまり、月76時間以上使うならXServer、76時間未満ならKAGOYAが安い。

自分の場合、平日は本業があってVPSを触る時間がないので、KAGOYAの時間課金のほうが合っています。あなたが24時間動かしたいタイプなら、XServerの固定料金一択です。

セットアップの簡単さ — XServerの「ワンクリック」は本当にラク

正直に言うと、セットアップの簡単さではXServerが一歩リードしています。

XServer VPSは「Claude Code / Codex専用イメージ」をワンクリックで構築できます。VPSを借りたその日からClaude Codeが使える状態。専門知識は要りません。

KAGOYA CLOUD VPSは公式でAIツール向けのセットアップ手順を提供していますが、自分で手順に沿って設定する必要があります。ターミナルに慣れている人なら問題ありませんが、初めてVPSを触る人にはハードルがあります。

筆者の判断

「コマンドって何？」レベルの人はXServer。 ターミナルでsshくらい打てるならKAGOYAでも問題なし。

無料お試し — KAGOYAの14日間は「あり」

XServer VPSには無料お試し期間がありません。借りたらその月から課金開始です。

KAGOYAには14日間の無料お試しがあります。

14日間って短いと思うかもしれませんが、週末が2回入ります。平日は仕事で触れなくても、2回の週末でClaude Codeの動作確認・使い勝手のチェックは十分できます。「合わなければやめる」が無料でできるのは大きい。

VPSでClaude Codeを動かす意味 — 「精神的な安心感」がデカい

「自宅のMac miniやRaspberry Piでもいいのでは？」と思うかもしれません。技術的にはそのとおりです。

でも実際にやってみると、PC立ち上げっぱなしって精神的に気になるんですよね。

  • 電気代が気になる
  • ファンの音が気になる
  • 何かあったときにリモートデスクトップで入らなきゃいけない
  • 全然「手放し」にならない

VPSなら、ブラウザやターミナルからさっとアクセスして、操作して、閉じる。自分のPCには一切負荷がかからない。 この「精神的な安心感」は、スペック表には載らないけど実際に使ってみるとかなり大きいです。
