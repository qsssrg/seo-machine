最初に結論を書きます

Claude Code目的なら、どちらもGPUプランは要りません。 これだけまず頭に入れておいてください。

使い方で分けると：

  • 月76時間以上使うなら → XServer VPS（830円固定のほうが安くなる）
  • 週末だけ・試してみたいだけなら → ConoHa VPS（時間課金で始める）

この判断だけで8割は決まります。以下でちゃんと説明します。

自宅PCでClaude Codeを動かしていると、「ファンがうるさい」「他の作業ができない」「PCを切れない」という状況になってきます。自分もそれで限界を感じてVPSに移行しました。

VPSにするとPCを完全に閉じられるし、作業が止まらない。精神的に全然ちがいます。ただ、PC立ち上げっぱなしで代わりにしようとすると「何かあったらリモートデスクトップで入らなきゃいけない」状況になって、結局手放しにならないんですよね。だからVPSは使う価値がある。

で、XServerとConoHaを比較するとき、まず一つ気にしてほしいことがあります。

GPUプランの話は一旦置いておいてください

比較表を見るとGPUスペックが並んでいますが、Claude CodeにGPUは不要です。

Claude CodeはAPIを経由してAnthropicのサーバーに処理を投げる仕組みなので、VPS側にGPUがあっても何も変わりません。「GPU搭載VPS = Claude Codeが速くなる」は完全に誤解です。

はっきり書いておきます。GPU推しの比較記事は、GPU VPSのアフィリエイト報酬が高い場合があります。Claude Code用途でGPUプランを勧めてくる記事は、少し疑ってみてください。

Stable DiffusionやローカルLLMを動かしたい場合は話が別です。そちらならGPUはあり。ただし月数万円かかるので「立ち上げが楽なら許容できる」という人向けです。

Claude Code用途なら、普通のVPSプランで十分。料金も格段に安くなります。

料金のわかりやすさ比較

XServer VPS：月830円〜（固定） ConoHa VPS：月2,178円〜（固定）／時間課金あり

実体験から言うと、「毎月いくらか計算したくない」タイプの人にはXServerの固定830円は精神的にラクです。月1日あたり約27円。これ以上かからないと分かっているのは安心感がちがいます。

ConoHaの時間課金は178円/時。1日2時間使うとして月に約1万円。週末だけ数時間なら月2,000〜3,000円に収まります。使い方次第でどちらが安いかが変わってくるので、自分の使い方をざっくり計算してみてください。

損益分岐点の計算：

XServerの固定830円 ÷ ConoHaの178円/時 ≒ 月4.7時間

……あれ、4.7時間？

正確に言うと、ConoHaの「月額固定プラン（2,178円）」との比較では別の話になります。時間課金（178円/時）との比較でXServerの830円固定が安くなるのは、月約4.7時間以上使う場合。

週1〜2時間しか使わない、という人なら時間課金のConoHaが安い。週末含め毎日少しでも使う人ならXServerの固定料金のほうが断然安くなります。

セットアップの簡単さ比較

XServer VPSにはClaude Code / Codex専用のワンクリック構築イメージがあります。ターミナルの知識がなくても環境が立ち上がります。これは非エンジニアにとって本当にありがたい。

ConoHaも直感的なコントロールパネルで迷いにくい設計です。「まず課金前に試してみたい」という場合、初期費用ゼロ・いつでも解約可能という点が安心感になります。

自分が重視するのはセットアップで詰まらないことです。最初に詰まると「自分には無理かも」となって止まってしまう。その意味でワンクリックイメージがあるXServerは一歩リードしていると思います。

日本語サポート比較

両方ともサポート体制は整っています。困ったときに日本語で問い合わせできる安心感は、非エンジニアには地味に大事です。どちらも問題なし。
