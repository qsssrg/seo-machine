マイクラ マルチサーバー向けVPSおすすめランキング【2026年最新】

【結論を先に書く】自分ならこう選ぶ

まず結論から。

  • 毎日〜週4以上遊ぶ → XServer VPS for Game（990円固定）
  • 週末だけ遊ぶ → ConoHa for GAME（時間課金）
  • コマンド操作に抵抗なくて安さ最優先 → KAGOYA CLOUD VPS

「とりあえず1位のやつでいいや」と思って毎日使わないのにXServerを選ぶと、ConoHaの時間課金より割高になるケースがある。このあと計算も含めて説明するので、自分の使い方を確認しながら読んでみてください。

友達と遊ぶならVPSが最強

マインクラフトで友達や家族とマルチプレイを楽しむには、専用のサーバーが必要です。

自宅PCでサーバーを立てる方法もあるんだけど、正直これはおすすめしない。

  • PCをつけっぱなしにする必要がある（電気代の問題もあるけど、それより何かあったときに手元のPCに入らないといけないのが地味にしんどい）
  • 自分がいない時間は友達が遊べない
  • ポート開放でセキュリティリスクが出る
  • PCのスペックが足りないとカクカクする

特に「自分がいない間も友達に遊んでてほしい」なら、自宅PC運用は完全に無理。VPSにしておけば、サーバーは24時間勝手に動いてる。自分は関係ない。これが一番の理由。

VPSなら月990円前後で、24時間稼働のマイクラサーバーが手に入る。

VPS選びの3つのポイント

1. メモリ容量

プレイ人数推奨メモリ
1〜4人2GB
5〜10人4GB
11〜20人8GB
MOD導入4GB以上

友達4人で遊ぶなら2GBで余裕。MODを大量に入れるなら4GBにしておいた方が後悔しない。

2. テンプレート対応

VPSサービスによっては「マイクラテンプレート」が用意されており、サーバー契約と同時にマイクラサーバーが自動構築されます。コマンド不要で初心者でも安心。

はっきり書いておくと、テンプレートの有無が初心者にとって一番大きな差。KAGOYAが安くても手動構築になるのはそこそこしんどい。「Linuxコマンドって何？」という人はXServerかConoHa一択でいい。

3. 管理ツール

ブラウザからサーバーの設定変更・バックアップ・バージョン更新ができる「マネージャーツール」があると便利です。

XServer vs ConoHa、損益分岐点を計算する

「どっちが安いか」を感覚で選ぶと損をする可能性があるので、ちゃんと計算しておく。

ConoHaの時間課金（2GBプラン）は公式によって変動するが、仮に1時間あたり約1.4円として計算すると：

月間使用時間ConoHa（時間課金）XServer（固定）
20時間約28円990円
50時間約70円990円
100時間約140円990円
200時間約280円990円
700時間（ほぼ24h稼働）約980円990円

本音を言えば、： マイクラサーバーを「友達が遊びたいときだけ起動」する運用なら、月700時間も稼働することはない。週末2日×8時間でも月64時間。この使い方ならConoHaの圧勝。

一方、「サーバーを常時起動しておきたい（自分がいない間も友達が遊べるように）」 という使い方なら、月700時間近くなるのでXServerの固定990円がトータルで安くなる。

要するに：

  • サーバーを「常時起動」するならXServer
  • 「遊ぶときだけ起動」するならConoHa

これだけ。

マイクラサーバーの立て方（XServer VPS for Gameの場合）

ステップ1：申し込み

  1. XServer VPS for Gameの公式サイトにアクセス
  2. プランを選択（友達4人なら2GBプランでOK）
  3. アプリケーションで「Minecraft Java版」を選択
  4. rootパスワードを設定
  5. 支払い情報を入力して申し込み完了

ステップ2：サーバー情報を確認

申し込み完了後、メールでIPアドレスが届きます。

ステップ3：マイクラから接続

  1. マインクラフトを起動
  2. 「マルチプレイ」→「サーバーを追加」
  3. サーバーアドレスにIPアドレスを入力
  4. 「完了」→サーバーを選択して接続

本当にこれだけ。 自分もはじめてVPSでゲームサーバー立てたとき、こんなに簡単なのかと思った。昔は全部手動だったのに、テンプレートの力はすごい。

よくある質問（FAQ）

PC同士で遊ぶならJava版、スマホやSwitch/PS/Xboxのプレイヤーも一緒に遊ぶなら統合版（Bedrock Edition）を選んでください。
XServer VPS for GameとConoHa for GAMEは、Forge版やSpigot版のテンプレートが用意されており、MOD導入が簡単です。KAGOYAの場合は手動でForgeをインストールする必要があります。
2GBプランで4〜5人、4GBプランで10人程度が目安です。大規模サーバー（20人以上）なら8GB以上を選びましょう。
VPSの月額料金のみです。マイクラサーバーのソフトウェア自体は無料です。ただし、マイクラ本体（Java版: 3,960円、統合版: 3,960円）の購入は別途必要です。
