よくある質問

Claude CodeなどのAPI利用型AI開発であればGPUは不要です。メモリ4GB以上のVPSで十分動作します。ローカルLLMの推論やStable Diffusionでの画像生成にはGPU（VRAM 8GB以上推奨）が必要になります。
CPU 2コア以上、メモリ4GB以上、SSD 50GB以上が推奨スペックです。XServer VPSやKAGOYA CLOUD VPSの中位プランで快適に動作します。Node.jsとClaude Code CLIのインストールだけで使い始められます。
月額固定プランなら2,000〜5,000円程度です。GPUを時間課金で使う場合、L4 GPUなら1時間150〜180円程度。月100時間使用で15,000〜18,000円の計算です。Claude Code用途なら月額固定VPSで十分なケースがほとんどです。
日本語サポート・安定した料金体系・国内規制対応が必要なら国内VPS（XServer/ConoHa/さくら）を選んでください。グローバルなAPIサービス構築や海外ユーザー向けサービスなら海外VPS（Vultr等）がコスト面で有利です。
7Bモデルでメモリ8GB＋GPU 8GB VRAM、13Bモデルで16GB VRAM以上が目安です。OllamaやvLLMをインストールし、モデルをダウンロードするだけで動かせます。さくらの高火力やConoHaのGPUサーバーが有力候補です。
