自分の判断：XServer vs KAGOYA、どっちを選ぶか

ここが一番聞きたいところだと思うので、正直に書きます。

損益分岐点を計算してみた

KAGOYAの2コア/2GBプランは時間課金で約11円/時間（月770円 ÷ 約28日 × 1日あたりの換算）。
XServerの2GBプランは36ヶ月契約で月830円の固定（実勢価格帯）。

月の稼働時間KAGOYA（11円/時）XServer（830円固定）安いのは
20時間/月約220円830円KAGOYA
50時間/月約550円830円KAGOYA
76時間/月約836円830円ほぼ同じ
100時間/月約1,100円830円XServer
常時起動（744時間）約8,184円830円XServer

結論：月76時間が損益分岐点。常時起動したいならXServer一択。

ただし、「毎月何時間使ったか計算したくない」「請求額が毎月変わるのが嫌」という人は、稼働時間に関わらずXServerの固定料金のほうが精神的にラクです。これは金額の問題じゃなくて、メンタルの問題。

VPSを使う理由、自分の考え

「自分のPCで常時起動すればいいじゃないか」と思う人もいるかもしれない。でも個人的には、PCを立ち上げっぱなしにする運用は精神的に気になります。電気代もそうだけど、何かあったときにリモートデスクトップで入らなきゃいけないから、全然「手放し」にならない。VPSなら何も気にせず閉じられる。この「閉じられる安心感」はかなりでかいです。

KAGOYA無料トライアルはアリか

KAGOYAには14日間の無料お試し期間があります。これ、結構使いやすい設計だと思っていて。理由はシンプルで、14日の中に週末が2回入るから。平日は仕事でほとんど触れなくても、2回の週末でじっくり動作確認できる。「試したけど結局触れなかった」になりにくい。

用途別の判断：迷ったらここを見てください

本音を言えば、「GPU付きVPSでClaude Codeを動かそう」という記事を見かけることがあります。誤解されたくないので書いておく。Claude CodeはAPIを叩くだけのツールなのでGPU不要です。 GPU付きVPSは月数万円かかるプランが多く、そこに誘導するのはアフィリエイト報酬が高いプランを売りたいだけの可能性があります。騙されないようにしてください。

唯一GPUが意味を持つのはStable Diffusionなどローカルで画像生成したい場合です。それでも月数万円はまぁまぁ高い。立ち上げが簡単なGPU VPSサービスがあるなら試す価値はあるけれど、コストは覚悟した上で。

ゲームサーバーについては、「やってみたいと思ったのなら一度やってみればいい」がシンプルな答えです。悩んでいる暇があったら、手を動かしたほうが早い。

個人開発者の典型的なVPS活用パターン

パターン1：Claude Code + GitHub Actions でCI/CDを構築する

# VPS側でGitHub Actionsのデプロイを受け取る設定
# deploy.sh（VPSに設置）
#!/bin/bash
cd /var/www/myapp
git pull origin main
npm install --production
pm2 restart ecosystem.config.js
echo "Deploy completed: $(date)"

# .github/workflows/deploy.yml
- name: SSH Deploy
  uses: appleboy/ssh-action@v1.0.0
  with:
    host: ${{ secrets.SERVER_HOST }}
    username: deploy
    key: ${{ secrets.SSH_PRIVATE_KEY }}
    script: bash /var/www/myapp/deploy.sh
